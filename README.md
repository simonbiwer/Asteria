# Asteria

## Background
This app was developed as part of the NASA Space Apps Challenge 2026.
The challenge tackled was _Lunar Landing Sites Navigator_.

## Challenge
During a mission on the moon sunlight and direct communication to earth
is needed. The exposure to both the sun and earth depends on the time
period the mission is conducted. For changing mission dates, a quick
assessment is needed which allows simple comparison between possible
moon landing sites.

## Solution
Asteria allows to select a time period and compares all 13 moon landing
sites selected by NASA based on their sunlight and earth exposure
throughout the selected period.

## Tech Stack
- Vite as build tool
- React as UI Framework
- Typescript
